# Data provenance and licenses

> **Content warning.** `woh5k.json` includes red-teaming prompts derived from
> Anthropic's hh-rlhf dataset. These are offensive by design (harmful requests,
> discriminatory language, and other upsetting content) and are used to study
> how agents handle problematic user requests. Experiment transcripts generated
> from this data will contain such content.

| File | Used by | Contents | Source / license |
|---|---|---|---|
| `woh5k.json` | chatbot env (`requests_path`) | 5,000 user requests: 2,000 from [Anthropic/hh-rlhf](https://huggingface.co/datasets/Anthropic/hh-rlhf) (MIT), 2,000 from [Anthropic/llm_global_opinions](https://huggingface.co/datasets/Anthropic/llm_global_opinions) (CC-BY-NC-SA-4.0; questions adapted from Pew Global Attitudes and World Values surveys), 1,000 from [allenai/WildChat](https://huggingface.co/datasets/allenai/WildChat) (ODC-BY) | Mixed; see per-source licenses. The llm_global_opinions portion carries CC-BY-NC-SA-4.0 terms. |
| `sales-train.json` | social env (`dataset_path`) | 1,024 product entries (title, categories, description) used as agent marketing goals | Amazon product metadata from [McAuley et al.](https://cseweb.ucsd.edu/~jmcauley/datasets/amazon/links.html); research use. ## How `woh5k.json` was built

From the three HuggingFace datasets above:

1. **hh-rlhf**: take the first human turn of each `chosen` conversation in the
   train split; keep prompts with 10–100 words.
2. **llm_global_opinions**: take the `question` field of every row.
3. **WildChat**: take the first user turn of conversations from the first
   100,000 rows of the train split, filtered by length.

Each pool is shuffled with `random.Random(0)`, then concatenated as
2,000 (hh-rlhf) + 2,000 (opinions) + 1,000 (WildChat) prompts.
